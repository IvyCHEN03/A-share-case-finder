# 信源优先级

## Tier 1：原始结论依据

| 信源 | 主要内容 |
|---|---|
| 上海证券交易所发行上市审核系统 | 招股说明书、问询回复、上市委及审核中心文件 |
| 深圳证券交易所发行上市审核系统 | 主板、创业板审核公开文件 |
| 北京证券交易所审核系统 | 北交所审核公开文件 |
| 中国证监会 | 监管规则、行政许可和注册批复 |

## Tier 2：一手镜像和专业文件

- 巨潮资讯网托管的原始公告及披露文件；
- 律师工作报告、法律意见书、保荐工作报告；
- 发行人公告；
- 荣大二郎神等对官方文件的结构化检索结果，但引用前必须回到原始 PDF 核对。

## Tier 3：仅用于发现线索

- Wind、iFinD、Choice、见微、烯牛、易董、价值在线；
- 企查查、天眼查；
- 券商/律所专题文章、公众号和媒体盘点。

## 使用纪律

1. Tier 3 不得单独证明案例成立。
2. 每个 A 类案例至少要有一份 Tier 1 或 Tier 2 原始文件支撑。
3. 分别核验数字、日期、主体身份和项目状态。
4. 核对同一文件的版本、披露日期和问询轮次。
5. 第三方预归类标签一律视为 D 类线索。
