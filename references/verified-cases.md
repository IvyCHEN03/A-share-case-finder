# 实证案例库（模板 · 使用者自行填充）

> 本文件用于沉淀经一手核验的真实案例，供同类检索直接复用。随 skill 发布时为空白模板——请在自己的使用过程中逐步填入，**案例库内容属于使用者的私有研究成果，不随 skill 公开分发。**

## 使用方式

每完成一类检索，把经过 Step 5 核验的案例按下方结构补入。字段设计与 `templates/case_output_template.md` 一致。

## 条目结构

### 案例类型：〔填写类型名，如"XX指标偏低""XX期间新增XX"等〕

**对应监管规则（Step 0 结论）**：〔文件名、条号、现行有效版本〕

**规则性质**：〔明确允许需说明 / 原则允许但有豁免清单 / 明确禁止〕

**盲区/待办**：〔尚未覆盖的子类型、待补核验的条目〕

## 核实层级说明（填写时对照）

- **A**：严格符合，且已读到一手文件条款原文——可直接引用
- **B**：高度接近但缺一项条件，或一手文件仅定位未读到原文——需补最后一步
- **C**：形似而实质不符（附排除理由）——用作反例
- **D**：仅二手线索，未做一手核验——仅供线索，勿引用

## 填写纪律

1. 任何写入 A 层级的案例，必须能回溯到具体一手文件的章节/页码。
2. 涉及终止/撤回项目，必须单独判断被检索的问题是否为终止主因，无证据则写"无法判断"。
3. 数字类案例按分层口径记录（如适用），不能只记一个总数。
4. 注明每条案例适用的规则版本及生效日期，避免跨版本误判。
