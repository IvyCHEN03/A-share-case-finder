# 常见案例类型概念树

仅用于建立检索词和初筛候选，不替代必要条件测试。

## 股权和股本

- 三类股东：契约型基金、资管计划、信托计划、穿透核查、发行前清理。
- 突击入股：新增股东、增资价格、入股价格、股份锁定、申报前时间窗口。
- 对赌清理：估值调整、回购权、优先权、附条件恢复。
- 员工持股平台份额转让：合伙份额、内部转让、退出机制；判断是否新增经济权益和新股东。

## 知识产权

- 第三方受让核心专利：受让时点、核心技术依赖、独占许可、技术来源。
- 与控股股东/实控人共有产权：确认双方是否共同登记为权利人。单纯许可、整体受让或分拆切割不属于严格共有产权案例；高校等非股东共有方单列近似案例。

## 独立性和关联交易

- 同业竞争：业务重叠、竞业限制、规避措施。
- 客户供应商重叠：交易公允性、商业合理性。

## 财务

- 上市前大额分红：分红时点、金额、补流募投。
- 收入跨期和差错更正：收入确认时点、追溯调整、影响期间。

## 上市结构

- 分拆上市：母公司持股、同业竞争、关联交易和业务独立性。
- 红筹/VIE 拆除：股权还原、外汇登记、37号文和拆除时点。

## 扩展规则

新增类型时补齐对象词、事项词、时点词、同义词、反向词和严格必要条件。不得因案例终止便推定被检索事项是终止主因。
