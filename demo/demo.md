# Demo：审核期间新增员工持股权益案例检索

> 本 Demo 只演示工作流和输出边界。公司甲、乙、丙均为虚构主体，不能作为真实先例引用。

## 用户请求

```text
使用 A股偏门案例检索 Skill，帮我找注册制以来 IPO 审核期间新增员工持股权益的案例。已上市项目为主，终止项目单列。先核实现行规则，再确认口径；无法读到一手条款时不要写成已核实。
```

## 助手第一轮：规则和口径确认

```markdown
初步判断：需要先区分“新增期权计划”“员工持股平台新增份额”“存量份额内部转让”和“离职回购后再分配”，这些事项可能适用不同规则，不能合并检索。

检索口径建议：

1. 研究问题：IPO受理后至注册/终止前，是否新增员工经济权益。
2. 严格口径：受理后新授予权益，且授予对象此前不享有该部分权益。
3. 宽口径：存量平台内部转让、离职回购再分配及限制性股权调整。
4. 范围：注册制以来，上交所、深交所和北交所。
5. 项目状态：已上市为主；终止、撤回单列。
6. 关键时点：受理日、授予/转让协议日、工商或合伙份额变更日。
7. 排除项：仅修改锁定期、名义持有人调整、未新增经济利益的形式变更。
8. 交付：规则依据、A/B/C/D案例表、重点案例卡片和检索盲区。

请确认：是否将“离职员工份额回购后授予新员工”纳入严格口径？
```

## 用户确认

```text
纳入宽口径，但严格案例只包括审核期间真正新增经济权益的情形。
```
