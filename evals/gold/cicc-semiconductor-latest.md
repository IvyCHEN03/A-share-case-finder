# R012 Gold：最新中金半导体无实控人项目

## 测试目的

验证模型在长对话中收到一个可独立成立的新检索任务时，能否重置口径，而不是继续用上一题的“外部投资人—员工持股平台—一致行动”结构筛选新案例。

## S1 口径

| 类型 | 条件 |
|---|---|
| hard | 中金公司作为保荐机构或联合保荐机构参与 |
| hard | 发行人属于半导体行业 |
| hard | 能在交易所一手问询回复中定位控制权相关回答 |
| hard | 优先最近申报、问询或上市项目，必须写明检索截止日和用于排序的日期 |
| preferred | 无控股股东、无实际控制人 |
| 交付 | 结论先行，给官方链接、文件名、章节/页码和可借鉴的回答逻辑 |

上一题的一致行动、表决权委托、员工持股平台均不是本题必要条件。

## 截止2026年8月17日的 Gold 候选

### 1. 长鑫科技（688825）—首选，S1 / A-E1

- 半导体 DRAM 项目，中金公司与中信建投联合保荐。
- 2026年7月27日在科创板上市，晚于盛合晶微，因此按“最新已上市项目”排在第一。
- 《第二轮预先审阅问询函回复》“问题1、关于控制权”集中于 PDF 第18—25页。
- 回答链路包括：第一大股东上层合伙企业决策机制、GP/LP权限、历史表决一致不当然构成一致行动、国资主体不谋求控制权承诺、股东会/董事会/经营管理实际运行。
- 一手文件：https://static.sse.com.cn/stock/disclosure/announcement/c/202512/002170_20251230_H2T8.pdf
- 上市公告：https://www.sse.com.cn/disclosure/announcement/listing/ipo/c/c_20260724_10826610.shtml

### 2. 盛合晶微（688820）—第二优先，S1 / A-E1

## 理想结论

> 截止2026年8月17日，最值得优先阅读的近期中金半导体无实控人项目是长鑫科技和盛合晶微。若“最新”按已上市日期排序，长鑫科技优先；若专门需要股权高度分散、机构股东和员工持股平台共存的完整治理论证，盛合晶微可作并列对照。

## 评分注意

- 本题测试“新任务口径重置”，不得用旧题 Gold 反向判定长鑫科技或盛合晶微为 C。
- `A-E1` 表示它们满足本题 S1，不表示它们满足其他一致行动或表决权委托问题。
- 如未说明检索截止日和“最新”的排序时点，不得给最新性满分。
