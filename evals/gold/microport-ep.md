# Gold Answer：微电生理无实控人一致行动案例

## 严格口径

上市前同时满足：

1. A股IPO并最终成功上市；
2. 发行人认定无实际控制人；
3. 一方为外部投资人；
4. 另一方为发行人员工持股平台；
5. 双方直接签署一致行动协议；
6. 一手文件能够核实协议方向、表决权比例和分歧解决机制。

## 基准结论

微电生理符合上述要求；在该口径下应列为A-E1严格案例。

```text
嘉兴华杰（华兴资本旗下外部投资人）41.11%
        │ 直接签署《一致行动协议》
        ▼
爱德博瑞（发行人员工持股平台）3.05%

合计：44.16%
分歧机制：不能达成一致意见时，以嘉兴华杰意见为准。
发行人结论：无实际控制人。
上市结果：2022年8月31日登陆科创板，代码688351。
```

## 监管判断链路

该案例不能简化成“签了一致行动协议仍能上市”。完整判断链路是：

1. 嘉兴华杰及爱德博瑞合计44.16%，微创投资及上海生晖合计42.28%，两组接近且均未过半；
2. 嘉兴华杰和微创投资提名董事人数相同，均未控制董事会半数席位；
3. 单一股东不能决定高级管理人员选聘或控制日常经营；
4. 股东大会、董事会和经营管理历史运行有效；
5. 相关股东作出锁定安排，支持控制权结构稳定；
6. 因此，一致行动关系本身不当然等于拥有公司控制权。

## 容易误判的点

1. 爱德博瑞内部有限合伙人对普通合伙人的授权，不是“外部投资人将其直接持有的发行人股份表决权委托给员工平台”。
2. 严格命中关系是“嘉兴华杰与爱德博瑞直接一致行动”，不是“双方分别和某个实控人一致行动”。
3. 爱德博瑞由嘉兴华杰委派董事顾哲毅实际控制，是分析平台独立性时应披露的事实，但不影响本测试集将该案例认定为符合用户给定口径。
4. 微电生理证明的是个案中该安排未导致控制权归属，不代表任何类似协议都能维持无实控人认定。

## 第二类问题的审慎结论

如果问题改为“外部投资人将其直接持有的发行人股份表决权委托给员工持股平台本身行使”，微电生理不属于该类型。在已检索的沪深IPO公开文件范围内暂未发现严格成功案例；不能据此声称市场上不存在，也不能把方向相反的委托案例计入。
