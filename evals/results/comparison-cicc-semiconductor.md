# 中金半导体新任务：两份回答成对评测

## 评测口径

原始任务：搜索最新的中金半导体行业项目，最好是无实际控制人，重点整理问询回复中的控制权回答。

这是新的独立检索任务。“最好无实控人”是 preferred；上一题的外部投资人、员工平台和直接一致行动均不得继承为硬条件。

Skill 触发是否在首次进度更新中展示，无法从两份最终答案单独观察，因此主表只评其余 90 分，并换算为百分制。

## 结论

回答2明显更优，适合作为 R012 Gold 的主要样本。回答1的纯内容质量换算为 73 分，但由于触发“新任务未重置口径”硬失败项，最终可交付分封顶为 40 分。

回答1的核心问题不是候选公司错，而是任务边界错：它把上一题的导师需求带进了新题，并因“与旧题更接近”将盛合晶微排在上市日期更新的长鑫科技之前。

回答2的优势是：

1. 将“最好无实控人”正确作为偏好，而两个候选又恰好都满足；
2. 用检索截止日和上市日期支撑“最新”排序；
3. 定位到问询回复的具体问题和页码，而不是只给公司名；
4. 将事实、规则、论证方法和可直接使用的项目组表述分层交付。

## 能否据此证明 Skill 优势

这一成对样本可以作为 **功能性证据**，展示 Skill 期望带来的四个可观察优势：口径重置、条件强度、一手证据锚定和下游 Memo 结构。

但仅凭两份现有回答不能宣称评分差全部由 Skill 造成。要测净增益，应在新任务中对同一模型、同一原始 Prompt、同一工具权限、同一时间上限运行“无 Skill / 有 Skill”至少各3次，且不向被测模型泄露两家公司和页码。

因此，面试中最稳妥的表述是：

> 我用这道新任务做了一次成对回归测试。高分答案不仅找到了正确候选，还能重置旧任务口径、把“最好”处理为排序偏好，并把最新性、官方文件和页码串成可复核的论证链。这证明了 Skill 的设计优势；是否有稳定的净增益，我会再用同模型无 Skill/有 Skill 多次盲测验证。
