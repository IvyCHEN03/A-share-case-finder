# 实证案例库（模板 · 使用者自行填充）

> 本文件用于沉淀经一手核验的真实案例，供同类检索直接复用。随 skill 发布时为空白模板——请在自己的使用过程中逐步填入，**案例库内容属于使用者的私有研究成果，不随 skill 公开分发。**

## 使用方式

每完成一类检索，把经过 Step 5 核验的案例按下方结构补入。字段设计与 `references/case-output-template.md` 一致。

## 双轴评级说明（填写时对照）

- **A**：满足当前严格口径全部硬性条件；**B**：缺一项可放宽条件；**C**：违反硬性条件或逻辑方向不同；**D**：信息不足，暂不能判断。
- **E1**：已读取一手原文；**E2**：只定位一手文件；**E3**：仅二手材料；**E4**：无可用证据。
- 只有A-E1可进入严格结论。C-E1是已核实的逻辑排除；D-E3是待核线索，不是反例。

## 填写纪律

1. 匹配度和证据度必须分开记录；任何进入严格结论的案例必须为A-E1，并可回溯到具体一手文件章节/页码。
2. 涉及终止/撤回项目，必须单独判断被检索的问题是否为终止主因，无证据则写"无法判断"。
3. 数字类案例按分层口径记录（如适用），不能只记一个总数。
4. 注明每条案例适用的规则版本及生效日期，避免跨版本误判。
